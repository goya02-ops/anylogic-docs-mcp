# Aviso sobre la documentación

La licencia MIT de este repositorio (ver [LICENSE](LICENSE)) cubre **únicamente el
código**: el servidor MCP, los scripts de descarga y conversión, el instalador y la
documentación del propio proyecto.

**No cubre** la documentación de AnyLogic (guía de usuario, javadoc, imágenes ni los
ficheros generados a partir de ellos: `corpus/`, `raw/` e `index.db`), que es propiedad
de **The AnyLogic Company** y está sujeta a sus propios términos de uso.

Este repositorio no distribuye esa documentación. Cada usuario genera su propia copia
local a partir de:

- el javadoc incluido en **su** instalación de AnyLogic, y
- el sitio público <https://anylogic.help>, respetando su `robots.txt`.

Uso previsto: consulta personal desde un agente de IA. No redistribuyas `corpus/`,
`raw/` ni `index.db`, ni los uses para entrenar modelos.
